# Girls Party — онлайн-приглашение

Одностраничное приглашение в бежево-розовой палитре с монограммой MR.
Открывается запечатанным конвертом: печать → свет → отгибается верхний клапан →
карточка выходит из конверта → кадр въезжает в бумагу и переходит в приглашение.
Музыка включается в момент нажатия на печать.

Секции: шапка, обратный отсчёт, строка-настроение, детали мероприятия,
программа, дресс-код. Подтверждения присутствия и кнопки карты нет.

## Что заполнить

Всё меняется в одном месте — блок `invitationData` в конце `index.html`:

```js
var invitationData = {
  title:"Girls Party",
  dateISO:"2026-10-17T15:00:00+05:00",   // дата и время мероприятия
  venue:"Ruxshona's home",               // место
  music:"assets/music.mp3",              // фоновая музыка
  schedule:[ ... ]                       // программа мероприятия
};
```

Дата и место подставляются автоматически в шапку, блок «Детали мероприятия»
и подвал. Вручную их править не нужно.

Пока `venue` пустой, везде выводится «Место уточняется».
Пока `music` пустой, кнопка звука скрыта.

## Музыка

Файл лежит в `assets/music.mp3`, десять минут, 5,4 МБ, играет по кругу.
Стартует по нажатию на печать и плавно набирает громкость за три секунды,
дальше её можно выключить кнопкой в левом нижнем углу.

Браузеры не дают включать звук без действия пользователя — поэтому именно
нажатие на печать и служит разрешением. Загрузка файла начинается ещё
на касании, до того как нажатие завершится, чтобы декодирование не пришлось
на первый кадр анимации.

## Производительность

Открытие конверта — самая тяжёлая часть страницы, поэтому оно идёт в двух
вариантах.

**Полный** — вся светопись: лучи из конверта, разлив света по клапанам,
вспышка, волна. Около 7,4 секунды.

**Облегчённый** — те же самые движения (клапан, подъём карточки, наезд
кадра), но без стопки полноэкранных размытых слоёв поверх. Около 4,3 секунды.
Включается сам, если:

- в системе стоит «уменьшить движение»;
- телефон сообщает о 4 ГБ памяти или меньше, либо о 4 ядрах или меньше;
- первые 0,7 секунды анимации идут медленнее 34 кадров в секунду — тогда
  страница переключается на ходу, не дожидаясь конца.

Последнее и есть главная страховка: не нужно угадывать модель телефона,
достаточно посмотреть на реальную частоту кадров.

Что ещё сделано ради плавности: монограмма на карточке гаснет до наезда
кадра, потому что у неё внутри объёмный фильтр и пересчитывать его при
увеличении в несколько раз дорого; убраны режимы наложения у зернистости;
слои света уменьшены, радиусы размытия срезаны; `will-change` включается
только на время движения, а не держится с загрузки страницы.

## Логотип

Монограмма встроена прямо в `index.html` двумя символами — так страница
остаётся одним самодостаточным файлом и её можно отправить как есть:

- `#mr-logo` — цветная версия (розовое золото, бежевые линии, камень).
  Используется в шапке и на карточке внутри конверта.
- `#mr-logo-flat` — плоский силуэт, красится через CSS `color`.
  Используется на сургучной печати (тёмно-розовый) и в подвале (бежевый).

Важно: у `<symbol>` viewBox обрезан по краям рисунка (`49 104 414 306`),
а у внешнего `<svg>` он обязан начинаться с нуля (`0 0 414 306`).
`<use>` ставит внутренний вьюпорт в точку (0,0) текущей системы координат —
если смещённый viewBox стоит и снаружи, верх и левый край монограммы
обрезаются.

В `assets/` лежат исходники: `logo.svg` и PNG 256/512 для иконки вкладки и
превью ссылки в мессенджерах.

## Превью ссылки

В `<head>` замените `https://example.com` на реальный адрес сайта —
иначе в WhatsApp и Telegram не подтянется картинка.

## Дресс-код

Четыре образца цвета в секции «Дресс-код» заданы прямо в разметке
(`--c` у каждого `<i>`). Меняются на любые другие.
